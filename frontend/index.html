¿qué pongo aquí?

La dirección del sitio que querés escanear, con https:// al inicio. Ejemplo: https://vellius.com. Poné la página principal: el motor encuentra el resto solo.

Autenticación

¿qué significa cada uno?

Ninguno: sitios que se ven sin cuenta.
Usuario + Contraseña: el motor entra solo con tus datos (el más fácil, recomendado).
Cookies: pegás las cookies de tu navegador, para logins difíciles.
Bearer Token: apps que usan tokens tipo JWT.

¿de dónde las saco?

Entrá al sitio en tu navegador, menú → "Herramientas para desarrolladores" → pestaña "Application" → "Cookies". Copiá cada una como nombre=valor separada por punto y coma.

¿qué es esto?

Una dirección que SOLO responde con tu sesión iniciada, por ejemplo una API que devuelve tus datos: /api/account/init. Dejala vacía: el motor la encuentra solo. IMPORTANTE: no pongas la página de login aquí, en apps JavaScript siempre parece "no logueado".

¿qué pongo aquí?

El mismo usuario o email que usás para entrar al sitio. Ejemplo: tucorreo@outlook.com.

¿por qué fallaría el login?

Tu clave tal cual la escribís al entrar. Si el login falla, casi siempre es el autocompletado del navegador que puso otra cosa: escribí los dos campos a mano. El nodo AUTH-STATUS te muestra el mensaje exacto del servidor cuando algo sale mal.

¿cuándo la uso?

Solo si ya sabés dónde está el login, ej: https://sitio.com/login. Vacía = el motor la encuentra analizando el sitio solo (recomendado).

¿de dónde lo saco?

En el navegador, herramientas de desarrollador → pestaña "Network" → tocá un pedido a la API → buscá el encabezado Authorization: Bearer ... y copiá lo que sigue de "Bearer".

El backend debe estar corriendo en :8000
